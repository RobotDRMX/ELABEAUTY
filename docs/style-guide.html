Temas del Sistema

El tema se aplica con el atributo data-theme en <html>. Se gestiona con ThemeService y se persiste en localStorage.

☀️ Claro (light)
Default. Fondo blanco, texto negro, acento pink #e6007e
🌙 Oscuro (dark)
Fondo #1a1a1a, texto #f0f0f0. Grises oscuros para superficies.
👁️ Daltonismo (colorblind)
Reemplaza el pink por azul #0077cc. Deuteranopia-friendly.
/* Tema oscuro — [data-theme="dark"] */ --background: #1a1a1a; --text-primary: #f0f0f0; --gray-100: #252525; --gray-200: #2e2e2e; /* Tema daltonismo — [data-theme="colorblind"] */ --primary-color: #0077cc; --primary-light: #3399ff; --primary-dark: #005599; /* ThemeService — uso en Angular */ themeService.setTheme('dark'); // aplica y persiste themeService.theme(); // signal: 'light' | 'dark' | 'colorblind'
